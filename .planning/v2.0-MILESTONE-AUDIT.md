## The Blocker (single root cause)

`initialize_db()` runs only in `main.py` (line 33), never in `core/service.py:main()` (the `shoppybot` entry point) or `BotService.__init__`. `migrate_legacy_paths()` only moves pre-existing files, so on a fresh install the `items` table is never created. Result: `shoppybot run`, `shoppybot items add`, `shoppybot items list` crash with `sqlite3.OperationalError: no such table: items`.

Fix (one line, idempotent): call `initialize_db()` in `core/service.py:main()` immediately after `migrate_legacy_paths()`. This makes the console entry path self-sufficient and equivalent to the `main.py` shim, closing MOD-01, MOD-03, CLI-01, CLI-03.
