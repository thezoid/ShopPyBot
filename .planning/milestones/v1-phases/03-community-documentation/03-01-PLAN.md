| public reporter to maintainer | Security vulnerability reports cross from an untrusted reporter to the project; must travel a private channel, never a public issue |
| contributor to repository | Contributor-supplied content (PRs, plugin code) crosses into the project; docs must reinforce no-secrets and env-var-only posture |

| T-03-02 | Information Disclosure | CONTRIBUTING.md / CODE_OF_CONDUCT.md | mitigate | Reinforce "no secrets/credentials committed; env vars only" in the plugin checklist, consistent with Phase 1 posture |
| T-03-03 | Spoofing | placeholder contact email | accept | Clearly-marked placeholder; maintainer replaces with a real verified channel before launch. No real address invented |
