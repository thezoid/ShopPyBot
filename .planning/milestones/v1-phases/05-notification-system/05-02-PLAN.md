<objective>
Implement the two local-and-outbound channels with the simplest transport: SoundNotifier
(wraps pygame helpers) and DiscordNotifier (single embed POST via requests).

Purpose: NOTIF-03 (sound) and NOTIF-04 (Discord embed). Both subclass the `Notifier` ABC
from Plan 01. Sound is synchronous (no executor); Discord runs its blocking POST via
`run_in_executor` so it never stalls the async loop. The secret webhook URL is read from
env and must never appear in any log line on failure.

Output: `notifications/sound_notifier.py` and `notifications/discord_notifier.py`, plus the
matching tests in tests/test_notifications.py flipped from xfail to passing.
</objective>
