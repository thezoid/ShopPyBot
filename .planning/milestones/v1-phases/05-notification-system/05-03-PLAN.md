<objective>
Implement the two credentialed network channels: EmailNotifier (stdlib smtplib) and
SmsNotifier (Twilio REST via requests). Both subclass the `Notifier` ABC from Plan 01 and
run their blocking transport via `run_in_executor`.

Purpose: NOTIF-05 (email) and NOTIF-06 (SMS send path; the startup opt-in gate already lives
in Plan 01's SmsConfig validator). Email uses configurable sender/recipients from
`notifications.email` and reads SMTP_PASSWORD from env. SMS reads TWILIO_ACCOUNT_SID /
TWILIO_AUTH_TOKEN / TWILIO_FROM from env. No secret (password, token, SID) may appear in any
log line; the Twilio endpoint URL embeds the SID and must never be logged.

Output: `notifications/email_notifier.py` and `notifications/sms_notifier.py`, with the
matching tests flipped from xfail to passing.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment -> EmailNotifier | SMTP_PASSWORD env-only |
| environment -> SmsNotifier | TWILIO_ACCOUNT_SID / TWILIO_AUTH_TOKEN / TWILIO_FROM env-only |
| notifiers -> SMTP / Twilio | outbound only; TLS handled by smtplib/requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-07 | Information Disclosure | EmailNotifier error logging | mitigate | SMTP_PASSWORD env-only; SMTP exceptions propagate to the dispatcher (which logs class + a static message); send never logs the password or str(exc) embedding it |
| T-05-08 | Information Disclosure | SmsNotifier URL/SID in logs | mitigate | Twilio SID embedded in endpoint URL; never log resp.request.url or full URL — log scrubbed "twilio/Messages.json" + status only; token/SID env-only |
| T-05-09 | Elevation of Privilege | accidental SMS send in test_mode | mitigate | SMS opt-in gate enforced at startup (Plan 01 SmsConfig validator); SmsNotifier only constructed when sms.enabled (wiring, Plan 05); disabled by default |
| T-05-10 | Tampering | newline injection in SMTP body via item fields | mitigate | item_name/item_url are internally generated (not user input); set_content handles encoding; no raw header concatenation (Don't Hand-Roll) |
</threat_model>
