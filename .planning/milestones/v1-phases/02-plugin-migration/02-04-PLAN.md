class RetailerPlugin(ABC):
    domain_patterns: list[str]
    def __init__(self, config): self.config = config; self.driver = None
    async def setup(self): ...
    @abstractmethod
    async def check_availability(self, url: str) -> bool: ...
    @abstractmethod
    async def auto_buy(self, url: str) -> bool: ...
    async def login(self) -> None: ...
    async def detect_captcha(self) -> bool: ...
    async def teardown(self) -> None: ...

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env vars (AMZ_/BB_ credentials, CVV) → plugin login/auto_buy | secrets enter the process; must never be logged or written to config.yml |
| retailer web pages → nodriver tab DOM | remote, untrusted page content drives selector matches |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Information Disclosure | login()/auto_buy() handling AMZ_/BB_ credentials and CVV | mitigate | Credentials read only from os.environ (SEC-01); CVV from getpass-collected runtime value threaded via self._cvv (SEC-02). No writeLog call includes credential or CVV values (verify: no f-string logs the email/password/cvv variables). Never persisted to config.yml. |
| T-02-09 | Spoofing | navigator.webdriver / automation fingerprint on retailer pages | mitigate | nodriver handles stealth architecturally (D-02); the Phase-1 Selenium CDP patch is intentionally NOT carried into these plugins. No --disable-web-security equivalent. |
| T-02-10 | Tampering | None-return from tab.select misused → AttributeError mid-checkout | mitigate | Every tab.select/tab.find result is None-guarded before .click()/.send_keys() (Pitfall 2); top-level try/except returns a safe bool so a drifting selector cannot crash the loop. |
| T-02-11 | Denial of Service | input() in login/captcha blocks the event loop | accept | Acceptable for the Phase-2 sequential loop (D-03); flagged with a "# Phase 4 ASYNC-03" comment for the later concurrency phase (Pitfall 6). |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs. nodriver==0.50.3 is the pre-existing locked, human-verified dep; os/nodriver only. No new deps. |
</threat_model>
