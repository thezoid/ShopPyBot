<objective>
Lock the `RetailerPlugin` ABC contract and the `PLUGIN_API_VERSION` constant in a new `core/` package. This is the interface every platform plugin will subclass in Phase 2. `check_availability` and `auto_buy` are abstract; `login` and `detect_captcha` ship working no-op defaults so a plugin can be check-only. The `driver` parameter stays untyped in Phase 1 to avoid importing nodriver into the ABC (type annotation is deferred to Phase 2).

Purpose: CORE-01 and CORE-02. Locking this contract early lets Phase 2 build against a fixed interface with no renegotiation.
Output: `core/__init__.py`, `core/plugin_base.py`, `tests/test_plugin_base.py`.
</objective>
