<objective>
Replace raw `yaml.safe_load()` config handling with a validated `pydantic-settings` schema. `AppConfig` (a `BaseSettings`) loads `config.yml`, validates every field at startup with actionable error messages, supports flat per-platform nested sections, emits a deprecation warning when legacy credential keys are detected, and lets environment variables override YAML so credentials never live in config.yml.

Purpose: CORE-05 (startup validation), CORE-06 (per-platform sections), CORE-07 (legacy-key migration warning), SEC-01 (credentials from env vars). This is the source-of-truth config object `main.py` will instantiate in plan 05.
Output: `core/config_schema.py`, `tests/test_config_schema.py`.

Discretion resolved: `AppConfig` will resolve the YAML path absolutely via `Path(__file__).parent.parent / "config.yml"` inside `settings_customise_sources` (RESEARCH Pitfall 2 — avoids the CWD-relative default). For test injection, support an optional `yaml_file` override so tests can point at a `tmp_path` fixture file (see test task). No `env_prefix` is used (single-user tool; RESEARCH Pitfall 6).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.yml (on disk) → AppConfig | Untrusted/user-edited YAML crosses into typed validation here |
| environment → AppConfig | Credentials enter only via env vars, never config.yml |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-CFG | Tampering / DoS | config.yml malformed input | mitigate | pydantic-settings validates types and required fields at startup; raises ValidationError with field path before the bot loop runs (CORE-05). Maps ASVS V5 input validation. |
| T-01-CRED | Information Disclosure | credentials in config.yml | mitigate | No credential fields on any model; env vars only via env_settings precedence (SEC-01). extra="ignore" plus legacy-key DeprecationWarning (CORE-07) catches stale credential keys. ASVS V2. |
| T-01-CFGPATH | Spoofing | CWD-relative yaml_file silently loading wrong/empty config | mitigate | Absolute path resolution Path(__file__).parent.parent / config.yml prevents silent default-fallthrough (RESEARCH Pitfall 2). |
</threat_model>
