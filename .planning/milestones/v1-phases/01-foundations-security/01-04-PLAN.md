Exact version pins prevent silent upgrade to a malicious release. |
| T-01-LOG | Information Disclosure | per-call config.yml read in tight loop | mitigate | Caching at import removes repeated file I/O in the polling loop; reduces attack surface for a swapped-in malicious config mid-run and removes a performance footgun. |
