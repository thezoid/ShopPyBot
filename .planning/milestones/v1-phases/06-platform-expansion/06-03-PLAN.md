<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| retail site DOM -> plugin | Untrusted page content read via selectors; bot-protection systems observe the browser |
| env vars -> plugin login | Credentials cross from environment into the browser session |
| config user_agents -> nodriver browser_args | Config-supplied UA string passed to the Chrome launch |
| config headless flag -> nodriver.start | Config-supplied boolean selects visible vs headless launch (Amazon/BestBuy + new plugins) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | Information Disclosure | login() credential handling | mitigate | os.environ.get only; on missing creds log a credential-free message and return; never interpolate email/password into any writeLog call (SEC-01) |
| T-06-07 | Information Disclosure | experimental WARNING log line | mitigate | The experimental-warning text is a static string naming the protection only; it contains no URL credentials, CVV, or env-var values |
| T-06-08 | Spoofing | UA rotation / headless toggle (dual-use) | accept | Anti-detection is dual-use but in-scope for personal use; docs are HONEST that it does not defeat PerimeterX/HUMAN Security/Akamai/CAPTCHA -- it only reduces signal at the margins (RESEARCH Security Domain) |
| T-06-09 | Tampering | config user_agents -> --user-agent browser_args | accept | UA strings are non-secret cosmetic config; only effect is the advertised UA; no injection beyond the single Chrome flag |
| T-06-10 | Tampering | config headless flag -> Amazon/BestBuy setup() | accept | headless is a non-secret boolean read defensively (defaults True when config absent); only effect is the documented visible/headless launch mode, no security impact |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages this phase (RESEARCH Package Legitimacy Audit: none); nodriver/random already present |
</threat_model>
