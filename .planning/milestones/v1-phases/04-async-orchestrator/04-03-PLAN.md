## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stdin (human) -> stdin-listener thread | Human presses Enter to signal intervention complete |
| plugin coroutine -> write queue -> sqlite3 | Purchase events serialized into the DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | Information Disclosure | stdin-listener thread | mitigate | Listener calls only sys.stdin.readline() then loop.call_soon_threadsafe(event.set); it never stores, echoes, logs, or forwards the typed bytes. CVV/credentials are handled by getpass BEFORE asyncio.run() in a separate synchronous scope. [VERIFIED design: RESEARCH Security Domain] |
| T-04-09 | Tampering | asyncio.Event set from non-loop thread | mitigate | Events set exclusively via loop.call_soon_threadsafe (the only thread-safe bridge); direct event.set() from the thread is forbidden (Pitfall 1) |
| T-04-10 | Denial of Service | write_queue.join() deadlock on shutdown | mitigate | join() wrapped in asyncio.wait_for(timeout=10) in finally before TaskGroup teardown (Pitfall 4) |
| T-04-11 | Denial of Service | one plugin exception cancels all tasks | accept | Per-item errors are caught and logged inside run_plugin; only a genuine browser crash surfaces as an ExceptionGroup, which is the correct fail-loud behavior for this single-user tool |
| T-04-12 | Repudiation | concurrent writes via single drain task | mitigate | All writes funnel through one _write_queue_drain task (ASYNC-05); plugins never call update_item_purchased directly, preventing concurrent-write races on the purchased flag |
| T-04-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages introduced this phase (RESEARCH: zero new deps). slopcheck N/A; no install tasks. |
