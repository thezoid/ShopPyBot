From core/config_schema.py (ProxyConfig):
- `class ProxyConfig(BaseModel)` with `enabled: bool=False`, `urls: list[str]=[]`, `max_failures: int=3`, `cooldown_secs: float=300.0`
- `@field_validator("urls", mode="before")` `validate_proxy_urls(cls, v)` raises `ValueError` (pydantic surfaces as `ValidationError`) when any URL has no scheme, no hostname, or `port is None` (config_schema.py:256-257). A valid `scheme://[user:pass@]host:port` passes.

From core/stealth.py:
- `async def setup_proxy_auth(tab, username, password)` — no-op when `username` is empty. When username set: defines closure `_on_request_paused(event)` (stealth.py:302-307) that does `asyncio.create_task(tab.send(fetch.continue_request(request_id=event.request_id)))`, adds the task to module set `_live_tasks`, and registers `t.add_done_callback(_live_tasks.discard)`. Handlers are registered via `tab.add_handler(fetch.RequestPaused, _on_request_paused)` and `tab.add_handler(fetch.AuthRequired, _on_auth_required)` then `await tab.send(fetch.enable(handle_auth_requests=True))`.
- `from nodriver.cdp import fetch` — `fetch.RequestPaused` is the event type; the handler receives an event object with `.request_id`.
- `class ProxyPool`: `__len__`→size() (stealth.py:221-222), `current()`→`Optional[_ProxyEntry]` returns `None` when no entries (stealth.py:231), `advance()`→`None` when no entries / all retired (stealth.py:243,249), `record_success(entry)` calls `entry.record_success()` (stealth.py:255-257). `ProxyPool.from_urls(urls, ...)` builds entries.

From core/registry.py:
- `PluginRegistry(config, plugins_dir, proxy_pool=None, captcha_solver=None)` — `_discover_plugins` runs at construction.
- `plugins_for_items(items)` (registry.py:122-136): for each `item[1]` (link) calls `_route_all`; appends matching plugin only if `id(plugin) not in seen`; `_route_all` returns None for a non-matching host (line 120 no-match branch).
- `async setup_for_items(items)` (registry.py:138-159): awaits `plugin.setup()`; on `Exception` logs `writeLog("Plugin setup failed: ... -- skipping", "WARNING")` and skips (does not abort) — lines 158-159.
- `async teardown_all()` (registry.py:161-170): awaits `plugin.teardown()` on each active plugin; on `Exception` logs `writeLog("Plugin teardown error: ...", "WARNING")`, never raises — lines 169-170.
