## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-PRICESTR | Tampering | _parse_price_to_cents | mitigate | Strip non-numeric chars with re.sub before float; reject empty/non-finite/<=0; never eval/exec scraped text. Unit-tested with malformed fixtures. |
| T-16-DOS | Denial of Service | get_price page load | accept | get_price wrapped in try/except returning None; a slow/failed scrape never crashes the poll loop. Low risk. |
| T-16-LEAK | Information Disclosure | notifier error paths | mitigate | Reuse existing secret-safe logging (class name + status only); no new str(exc)/URL logging added. |
| T-16-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed this phase (RESEARCH audit: none). |
</threat_model>
