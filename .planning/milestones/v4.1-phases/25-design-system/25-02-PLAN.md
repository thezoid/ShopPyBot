|----------|-------------|
| GitHub release → repo | Vendored uPlot binary crosses from an external source into committed repo files |
| browser → static CSS | CSS is served to the browser; an external `url()` would create a new network surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-02 | Spoofing | CDN supply-chain via external CSS/JS URL | mitigate | All assets committed locally; no CDN; `test_no_external_urls_in_static` enforces zero `url(http`/`@import url(` in CSS |
| T-25-03 | Tampering | uPlot vendored binary integrity | mitigate | Download pinned to GitHub tag 1.6.32; verify size/banner before commit; committed binary served by StaticFiles, no runtime fetch |
| T-25-04 | Information Disclosure | dark-mode rule leaking light colors (cosmetic, not security) | accept | Token-only `components.css` plus `test_no_hardcoded_hex_in_components` guarantees theme uniformity; no security impact |
| T-25-SC | Tampering | npm/pip/cargo installs | accept | No registry installs; uPlot is a direct GitHub-tag download, not a package-manager dependency — slopcheck/legitimacy checkpoint not applicable per RESEARCH Package Legitimacy Audit |
