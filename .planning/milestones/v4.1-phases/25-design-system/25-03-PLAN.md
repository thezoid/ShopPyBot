| Boundary | Description |
|----------|-------------|
| API JSON → DOM | `item.name`/`item.link`/`cred.name` are operator-supplied via the API and were rendered with `innerHTML` (the active XSS vector) |
| browser localStorage → page | theme value read by the FOUC script; constrained to `'dark'`/`'light'` checks |
| non-local network → dashboard | banner + CSRF origin gate are the security model; banner must remain intact |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Tampering | Stored/reflected XSS via `item.name`/`item.link` in loadItems() (line 241) | mitigate | Replace `tr.innerHTML` with `createElement`+`textContent`; Remove button via `addEventListener`; `test_no_innerHTML_with_api_data` enforces no regression |
| T-25-05 | Tampering | Stored XSS via `cred.name` in loadCredentials() (line 255) | mitigate | Replace `div.innerHTML` template literal with full `createElement` build; `cred.name` set via `textContent` |
| T-25-06 | Tampering | Self-XSS via theme-toggle aria-label | accept | aria-label is a hardcoded string constant set via `setAttribute`; never API data — no injection surface |
| T-25-07 | Elevation of Privilege | MC-4 non-local banner / CSRF origin gate weakened by redesign | mitigate | Zero Python changes; `{% if is_non_local %}` block + banner copy preserved verbatim; `test_banner_renders_when_non_local` is a phase done-condition |
