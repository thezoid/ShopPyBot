<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bot daemon thread -> uvicorn event loop | The bot thread writes HealthRegistry on its own private loop; _poll_loop (uvicorn loop) reads get_status() via asyncio.to_thread. asyncio.Queue is not thread-safe; the bot thread must never touch SseHub/queues. |
| log file -> SSE producer | tail_log_lines reads the on-disk log via to_thread (sync file I/O off the loop); cursor prevents full re-reads and duplicate frames. |
| producer -> per-client queue | broadcast puts frames into bounded queues; a slow/dead client must not exhaust memory. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03 | Tampering / Availability | cross-loop asyncio.Queue corruption | mitigate | SseHub + _poll_loop are the SOLE producer on uvicorn's loop; module imports nothing from core/orchestrator (grep-enforced in acceptance); bot thread never references queues (Pitfall 1, the critical bridge invariant) |
| T-27-02 | Denial of Service | unbounded per-client queue (slow client) | mitigate | asyncio.Queue(maxsize=100) + drop-oldest in broadcast (get_nowait before put_nowait); producer never blocks |
| T-27-04 | Denial of Service | full-file re-read per tick / loop-killing exception | mitigate | cursor-based tail_log_lines (no full re-read, Pitfall 6 rollover handled); _poll_loop catches per-tick Exception, logs class name, continues — a single read error never kills the stream |
| T-27-01 | Information Disclosure | error logging leaking secrets | mitigate | error branch logs exc.__class__.__name__ only, never str(exc) (SSE-03); grep-asserted zero `str(exc)` |
| T-27-SC | Tampering | npm/pip/cargo installs | accept | No package installs; RESEARCH.md Package Legitimacy Audit confirms zero new packages. No legitimacy checkpoint required. |
