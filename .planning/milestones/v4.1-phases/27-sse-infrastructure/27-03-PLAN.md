<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/curl -> /api/events | The one new localhost GET surface; untrusted client opens a long-lived stream. No query params, no body — nothing to validate (ASVS V5 n/a). Localhost-bound; non-local warning banner is the access model. |
| server -> browser (SSE frame) | Frames carry get_status() + log lines; could leak secrets if unscrubbed (handled Phase 26 + Plan 02 error logging). |
| client disconnect -> generator | A closed client must release its queue or the hub leaks memory. |
| ASGI lifecycle -> _poll_loop | The poll task must start on uvicorn's loop and stop cleanly on shutdown; a mis-placed task corrupts the loop binding. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-02 | Denial of Service | generator/queue leak on disconnect | mitigate | _event_generator finally: hub.unsubscribe(queue) runs on break, CancelledError, and generator close; test_sse_disconnect_cleans_hub asserts SseHub._queues empty after stream context exits (criterion 2) |
| T-27-01 | Information Disclosure | /api/events data frames | mitigate | status frames flow through the Phase-26-scrubbed get_status(); test_sse_no_credential_patterns asserts no @/password/token/key=/cvv and no email-like string in live frames (SSE-03 carryover) |
| T-27-03 | Tampering / Availability | _poll_loop task created on wrong loop / cross-loop binding | mitigate | asyncio.create_task(_poll_loop(...)) is created ONLY inside the lifespan coroutine on uvicorn's loop (Pitfall 2); SseHub() built synchronously in factory body so app.state.sse_hub always exists (Pitfall 3) |
| T-27-05 | Spoofing / Tampering | CSRF on the streaming GET | accept | GET is safe/idempotent and read-only; no check_origin needed (matches existing /api/status, /api/logs GET posture); localhost-bound single-operator tool — CSRF + non-local banner are the held security model |
| T-27-SC | Tampering | npm/pip/cargo installs | accept | No package installs; RESEARCH.md Package Legitimacy Audit confirms zero new packages. Raw starlette StreamingResponse only. No legitimacy checkpoint required. |
