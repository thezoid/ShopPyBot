<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser/curl → GET endpoints | Untrusted query/path input (level, search, n, link_b64) crosses into the read path |
| event loop → blocking sync reads | SQLite + file reads must not stall uvicorn's single event loop |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-03 | Denial of Service | GET /api/logs `n` param | mitigate | Silently clamp n with min(n, 500) before read (RESEARCH lines 440-443); FastAPI rejects non-integer n with 422 |
| T-26-04 | Denial of Service | sync reads in async handlers | mitigate | All three reads wrapped in asyncio.to_thread so the event loop is never blocked (SSE-03); acceptance_criteria greps confirm each wrap |
| T-26-05 | Tampering | log file path from request | accept | read_recent_logs builds the path from datetime.now().strftime, no user input enters the path (RESEARCH line 541) — no traversal surface |
| T-26-06 | Information Disclosure | bad link_b64 / 5xx error surfaces | mitigate | price-history returns {"series": []} on any decode failure (no exception detail leaks); generic empty rather than echoing input |
| T-26-07 | Spoofing/Elevation | new GET endpoints + CSRF | accept | GET endpoints are read-only; check_origin (CSRF) intentionally omitted, consistent with existing /api/status and /api/logs (reads, not mutations) |
| T-26-SC | Tampering | npm/pip/cargo installs | accept | No package installs; stdlib (asyncio, base64) + existing fastapi only; RESEARCH Package Legitimacy Audit: not applicable |
</threat_model>
