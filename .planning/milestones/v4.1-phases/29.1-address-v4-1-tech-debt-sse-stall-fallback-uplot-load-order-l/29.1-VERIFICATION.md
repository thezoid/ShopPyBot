1. **OBS-05: Cold-load chart render (no ReferenceError)**

   Test: Hard-refresh the dashboard with DevTools cache disabled (Network tab, Disable cache). Inspect the browser console for errors.
   Expected: No `ReferenceError: uPlot is not defined`; price chart renders without errors on first paint.
   Why human: A ReferenceError is a browser JS engine runtime event. Static grep confirms the tag is before `</head>` and the inline script, but cannot exercise the JS parse order in a real browser.

2. **SSE-01/02: Stall-then-fallback observable timing**

   Test: With the dashboard open and SSE active, throttle or drop the server's `/api/events` endpoint (e.g., DevTools network throttle, or pause the generator) so the stream stays open but delivers no `status` events for 10+ seconds. Watch the SSE indicator.
   Expected: Within ~8-10 seconds the indicator flips to "Reconnecting"; `/api/status` and `/api/logs` XHR requests appear in DevTools Network. Restore the stream; indicator returns to "Live" and fallback polling stops.
   Why human: Requires a live EventSource stream that goes idle without closing — this is not reproducible via static-content grep.

3. **OBS-07: Repeated bot messages visible after filter repaint**

   Test: Apply a log-level filter or search term (to trigger a `renderLogLines` repaint), then trigger repeated identical consecutive bot log lines via the live SSE stream.
   Expected: The first post-backfill SSE line that duplicates the last backfilled line is silently dropped (boundary overlap). All subsequent identical lines are appended and visible in the log viewer.
   Why human: Requires a live SSE log stream and repeatable identical messages. Behaviour depends on runtime sequencing of backfill vs SSE delivery.
