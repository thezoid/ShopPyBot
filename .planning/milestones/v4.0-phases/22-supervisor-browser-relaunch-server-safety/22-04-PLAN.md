<objective>
Add the cross-platform signal bridge (`_register_signals`) and the pre-teardown write-queue flush (`_flush_write_queue`) to `core/orchestrator.py`, and wire both into `async_main`, so SIGTERM/SIGINT trigger a cooperative teardown that flushes pending DB writes before closing browsers (SRV-02).

Purpose: A container/systemd stop sends SIGTERM; on POSIX `loop.add_signal_handler` registers cleanly, but on Windows `ProactorEventLoop` it raises `NotImplementedError`, so the bridge falls back to `signal.signal`. Both paths use `loop.call_soon_threadsafe(root_task.cancel)` (the same thread-safe pattern as `BotService.stop()`), which propagates `CancelledError` into the TaskGroup for an orderly shutdown. The existing `finally` block's bare `queue.join()` can hang for ~10s on an in-flight item left un-`task_done`'d by the cancelled drain task; a manual `get_nowait()` drain pass first processes remaining items so no pending DB write is lost on shutdown.

Output: `_register_signals` + `_flush_write_queue` helpers; `async_main` registers signals at startup and runs the manual flush in `finally` before `teardown_all()`; new `tests/test_signal_bridge.py`.
</objective>

| Boundary | Description |
|----------|-------------|

| in-flight write-queue item -> shutdown | a cancelled drain task may leave one DB write un-applied at teardown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-22-04 | Tampering | signal handler touching loop/task state across threads | mitigate | use loop.call_soon_threadsafe(root_task.cancel) in both POSIX and Windows paths (the only thread-safe bridge) |
| T-22-05 | Denial of Service | orphaned Chrome on container/systemd stop | mitigate | SIGTERM/SIGINT trigger cooperative teardown; registry.teardown_all() runs after the write-queue flush so browsers are closed cleanly |
| T-22-06 | Denial of Service | queue.join() deadlock on an in-flight item left by the cancelled drain task | mitigate | manual _flush_write_queue get_nowait + task_done pass before join(); join timeout reduced to 5s safety valve |
