<objective>
Create the new `core/confirmation.py` module with `detect_order_confirmation(tab, platform)`
— the pure detector the orchestrator (Plan 04) calls after `auto_buy()` returns True. It
applies a ~3s settle delay, reads the live tab URL, matches a per-platform confirmation URL
fragment (URL-first, HIGH confidence), then extracts an order id via Amazon's `orderID`
URL query param or a DOM order-number selector (backup). If the URL matches but no id is
extractable, it returns a `CONFIRMED-<ts>` sentinel so `purchased` is still written on a
real confirmation (BUY-03).

Purpose: Isolate all URL/DOM confirmation parsing in one testable module with no plugin
coupling beyond the nodriver tab API.
Output: `core/confirmation.py` + `tests/test_confirmation.py` (FakeTab-driven unit tests).

Note: This plan creates the contract `async def detect_order_confirmation(tab, platform)
-> str | None`. Plan 04 (Wave 2) imports and wires it. This is a Wave 1 parallel-safe
module (no file overlap with Plans 01/03).
</objective>
