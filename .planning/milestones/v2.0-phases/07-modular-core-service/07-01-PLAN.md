<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| front-end → BotService.start(cvv) | CVV/secret crosses from caller into the service as a parameter |
| BotService → orchestrator → plugin browsers | service owns background run + browser lifecycle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Information Disclosure | CVV passed into start()/run() | mitigate | CVV is a method parameter only; never written to a log line, never stored as an attribute that gets logged. Forward it into async_main exactly as main.py does today; no new log statements that include cvv. |
| T-07-02 | Information Disclosure | get_status()/list_items() output | mitigate | Return non-secret plain data only (running flag, item name/link/qty/purchased). Never include cvv or credential values in returned dicts. |
| T-07-03 | Denial of Service (resource leak) | stop() leaving orphaned Chrome | mitigate | stop() routes through async_main's existing shutdown path which awaits registry.teardown_all(); a service test asserts teardown is reached on stop(). |
| T-07-04 | Tampering | interactive input in core | mitigate | core/service.py contains no getpass and no input(); enforced by tests/test_no_input.py scanning core/. |
| T-07-SC | Tampering | npm/pip installs | accept | No new dependencies this phase (locked). No install task here; package-build install is Plan 02. |
</threat_model>
