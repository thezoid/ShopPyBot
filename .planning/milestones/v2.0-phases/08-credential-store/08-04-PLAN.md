<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| consumers → get_store() | Plugins/notifiers must read secrets only through the store facade |
| os.environ → migrate_from_env → backend | Migration moves secrets from env into at-rest backend; values never printed |
| --migrate CLI output → terminal | Only key NAMES may cross to stdout, never values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-13 | Information Disclosure | a missed consumer keeps reading os.environ, bypassing the store/log scrub | mitigate | test_no_os_environ_secret_reads (Task 3) scans plugins/notifications/core and fails on any new os.environ secret read |
| T-08-14 | Information Disclosure | --migrate prints secret values to the terminal/scrollback | mitigate | migrate_from_env returns NAMES only; main() prints "Migrated: {key}"; test_main_migrate_flag asserts no value in output (Task 2) |
| T-08-15 | Denial of Service | DiscordNotifier KeyError on missing webhook crashes the dispatcher | mitigate | get_store().get returns None; explicit ValueError guard replaces the implicit KeyError (Task 1, Pitfall 2) |
| T-08-16 | Information Disclosure | migrate_from_env logs/echoes a secret value during import | mitigate | only store.set + append key name; no print/log of val anywhere in the loop (Task 2) |
</threat_model>
