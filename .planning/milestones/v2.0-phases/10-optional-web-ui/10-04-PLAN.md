<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/config | untrusted config-key write crosses here |
| server template → browser HTML | user-controlled item name/URL rendered to HTML (XSS surface) |
| app.state.is_non_local → banner | controls whether the exposure warning is shown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-12 | Tampering | config key injection writes arbitrary yaml keys | mitigate | WEB_ALLOWLIST gate in config.py + write_web_config; unknown key -> 422, no write |
| T-10-13 | Tampering | stored-XSS via item name/URL echoed into dashboard HTML | mitigate | Jinja2 auto-escaping on all `{{ }}`; no `| safe` for user data; verified absent in CSS/template checks |
| T-10-14 | Spoofing | local-malware CSRF POSTs config to 127.0.0.1 | mitigate | dependencies=[Depends(check_origin)] on POST /config |
| T-10-15 | Information Disclosure | credential value pre-filled into a template input | mitigate | Credential inputs are empty type=password; no value in template context; runtime SC3 test asserts a seeded secret is absent from GET / response.text |
| T-10-16 | Elevation of Privilege | non-local bind hides exposure from the user | mitigate | In-page #fee2e2 banner when is_non_local (HTML half of GUI-06; stderr half in Plan 01) |
</threat_model>
