<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/items, /api/bot/* | untrusted HTTP mutates DB / bot lifecycle |
| log file → /api/logs response | server-side log content returned to browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04 | Spoofing | local-malware CSRF against POST/DELETE item + bot routes | mitigate | dependencies=[Depends(check_origin)] on every mutating route; 403 on origin mismatch |
| T-10-05 | Tampering | web routes bypass BotService to touch models/orchestrator | mitigate | Access only via request.app.state.svc; test_web_mod02.py AST guard enforces no forbidden imports |
| T-10-06 | Information Disclosure | secret leaks via /api/logs | accept | CRED-06 guarantees writeLog never logs secrets; reader returns lines verbatim, no new sink |
| T-10-07 | Tampering | XSS via item name/URL echoed to browser | accept | /api routes return JSON (not HTML); template escaping handled in Plan 05; JSON responses are not HTML-interpreted |
| T-10-08 | Denial of Service | blocking svc.stop() (15s thread.join) stalls uvicorn's single event loop | mitigate | /bot/stop is async and dispatches svc.stop via run_in_executor; the event loop stays responsive during shutdown |
</threat_model>
