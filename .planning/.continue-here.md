<decisions_made>

- **Drop Selenium → nodriver 0.48.1**: async-native CDP-direct, official successor to undetected-chromedriver; requires Python 3.9+ (floor set to 3.11)
- **Plugin interface**: ABC with 4 methods; only `check_availability` and `auto_buy` abstract; `login`/`detect_captcha` have no-op defaults so plugins can be check-only
- **Plugin naming**: `shopbot_plugin_*.py` in `plugins/`; importlib auto-discovery; non-matching files get a warning log
- **Plugin distribution**: plugins/ folder + GitHub wiki; no PyPI packaging
- **Concurrency**: `asyncio.TaskGroup` + `ThreadPoolExecutor`, one driver per plugin (NOT shared global driver)
- **Config**: `pydantic-settings[yaml]` replaces raw `yaml.safe_load()`; flat per-platform sections (`platforms.amazon.email`)
- **Credentials**: env vars only; CVV via `getpass` at runtime; never in config.yml
- **Python floor**: 3.11 (TaskGroup + pydantic-settings 2.x requirement)

## Critical Anti-Patterns (do NOT repeat these)

- **Shared global WebDriver**: current code has one shared `driver` — must NOT be carried forward; each plugin owns `self.driver` in `__init__`
- **config.yml re-read per log call**: `logger.py` currently reloads config on every `writeLog()` call — fix in Phase 1 (INFRA-02)
- **Credentials in config.yml**: current `sample.config.yml` has plaintext email/password fields — Phase 1 (SEC-01) moves all to env vars
- **`--disable-web-security` flag**: instant bot-detection signal — remove in Phase 1 (SEC-03)
