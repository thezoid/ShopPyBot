ProxyPool / _ProxyEntry design (RESEARCH Pattern 4 — contract Plan 03 consumes):
  _ProxyEntry fields: url, host_port, username, password, failures=0, retired_until=0.0
    .is_retired() -> bool                                   # time.monotonic() < retired_until
    .record_failure(max_failures, cooldown_secs) -> bool    # True if just retired
    .record_success() -> None                               # resets failures
  ProxyPool(entries, max_failures=3, cooldown_secs=300.0):
    .current() -> Optional[_ProxyEntry]
    .advance() -> Optional[_ProxyEntry]   # next non-retired; None if all retired
    .record_failure(entry) / .record_success(entry)
    .from_urls(urls, max_failures, cooldown_secs) classmethod

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config.yml (proxy.urls) → ProxyPool | Proxy URLs (may contain user:pass@) cross from disk into memory; credentials must never reach logs |
| browser (untrusted page) → _is_ban_response | Retailer response body/status is untrusted input scanned for ban phrases |
| proxy server → Chrome (Fetch auth) | 407 challenge answered with stored credentials via CDP |
| WebRTC UDP → real network | Without the launch flag, STUN leaks the real IP around the proxy tunnel |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Information Disclosure | _ProxyEntry.url / ProxyPool / build_proxy_browser_args | mitigate | host_port stored separately from url; build_proxy_browser_args uses host_port only (test asserts the credentialed url never appears). No log references entry.url. |
| T-13-02 | Information Disclosure | setup_proxy_auth / proxy exception paths | mitigate | Any except logs only `exc.__class__.__name__`, never `str(exc)` (Pitfall 9). Credentials passed to AuthChallengeResponse only, never logged. |
| T-13-03 | Tampering | _parse_proxy_url input | mitigate | stdlib `urllib.parse.urlparse` (ASVS V5) — no custom split; handles malformed/IPv6/missing-creds. |
| T-13-07 | Information Disclosure | WebRTC real-IP leak | mitigate | build_proxy_browser_args always appends `--force-webrtc-ip-handling-policy=disable_non_proxied_udp` (Pitfall 3, ANTI-04 SC4). Test asserts the flag is present. |
| T-13-08 | Denial of Service | setup_proxy_auth handler deadlock | mitigate | Handlers wrap tab.send in asyncio.create_task (Pitfall 5); add_handler before fetch.enable (Pitfall 4). Test asserts ordering. |
| T-13-SC | Tampering | npm/pip/cargo installs | accept | No package installs. RESEARCH Package Legitimacy Audit: no new packages (nodriver 0.50.3 pinned + approved). |
