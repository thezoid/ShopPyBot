  out-of-scope refactor).

  that the banner HTML renders. Add a `TestClient` regression test asserting the banner text appears
  in the dashboard response when `is_non_local=True`, and is absent when `is_non_local=False`. This
  is the automatable portion of MC-4 (the live-browser render confirm is documented in Plan 04).

Purpose: Close the TD-4 regression-test requirement for BOTH write seams without a refactor (the
credential seam via the existing named test, the config seam via a new test + accepted-gap comment),
and convert the MC-4 banner behavior from "documented manual" to a CI-enforced assertion.

doc note in web/config_web.py. (The credential-seam test already exists; this plan only names it as
