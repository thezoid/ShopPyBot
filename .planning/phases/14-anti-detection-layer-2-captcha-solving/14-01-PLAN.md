2captcha v1 HTTP protocol (verified in RESEARCH.md Patterns 1-3):
- Submit reCAPTCHA: POST https://2captcha.com/in.php
  data={key, method=userrecaptcha, googlekey=<sitekey>, pageurl, json=1}, timeout=30
  -> body.json(); status==1 means body["request"] is the captcha_id, else error.
- Poll: GET https://2captcha.com/res.php params={key, action=get, id, json=1}, timeout=10
  Initial wait 15s, then 5s interval, max ~20 polls (stays < 120s).
  status==1 -> body["request"] is the token; "CAPCHA_NOT_READY" -> keep polling; else raise.
- Balance: GET https://2captcha.com/res.php params={key, action=getbalance}, timeout=10
  text float (e.g. "3.45"); text starting "ERROR_" is an error (ERROR_ZERO_BALANCE -> treat as zero).
