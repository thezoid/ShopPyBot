This is the central contract change of the phase. v1's `check_availability(self, url)` stays but becomes async; `auto_buy` drops its `(driver, url, config)` parameters down to `(self, url)`; `login`/`detect_captcha` drop their `driver`/`config` params and become async no-op defaults; `__init__(self, config)`, `async setup()`, and `async teardown()` are added; `PLUGIN_API_VERSION` bumps 1→2; and `domain_patterns: list[str]` is added as a class annotation.

The Wave 0 tests (Plan 01) already encode this contract and are RED until this plan lands. This plan turns them green.

Purpose: lock the v2 plugin interface that every plugin, the registry, and the async main loop depend on.

class RetailerPlugin(ABC):
    domain_patterns: list[str]
    def __init__(self, config) -> None: self.config = config; self.driver = None
    async def setup(self) -> None: ...        # registry awaits; subclasses build nodriver Browser here
    @abstractmethod
    async def check_availability(self, url: str) -> bool: ...
    @abstractmethod
    async def auto_buy(self, url: str) -> bool: ...
    async def login(self) -> None: return None
    async def detect_captcha(self) -> bool: return False
    async def teardown(self) -> None: ...
