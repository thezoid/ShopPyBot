`setInterval(pollStatus` / `setInterval(pollLogs` and requires them only after the `else`
branch. The SSE watchdog's fallback timer MUST use the anonymous-wrapper shape
`setInterval(function() { pollStatus(); pollLogs(); }, POLL_MS)` — never the bare form —
or this test goes RED.
