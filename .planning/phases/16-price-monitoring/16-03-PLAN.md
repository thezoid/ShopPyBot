<objective>
Wire price monitoring into the async poll loop: call `get_price()` in a separate try/except inside `_check_and_buy` after `check_availability` succeeds, record to `price_history` (reading the previous price BEFORE appending), evaluate the absolute + percentage triggers with separate dedup, dispatch one `price_drop` event via the existing dispatcher, and seed per-item config into the items table at startup. Also add the read-only `BotService.get_price_history` accessor for the CLI plan.

Purpose: This is the integration plan that makes price monitoring work end-to-end. It depends on the schema/models (Plan 01) and the get_price hook + event fields (Plan 02).
Output: Extended `core/orchestrator.py`, `core/service.py`, `main.py`, and `tests/test_price_alert.py`.
</objective>
