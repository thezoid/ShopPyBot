Wrap the import-time `pygame.mixer.init()` in `utils.py` so the module imports
cleanly on a headless host with no audio device (SRV-01). On init failure, set a
module flag `_AUDIO_AVAILABLE = False`, log a one-time INFO, and make the play
functions silent no-ops. The bot must import and run unattended on a server.

Purpose: Close SRV-01 — the only thing blocking a headless server deployment.
Output: guarded `utils.py` + `tests/test_utils_audio.py`.

This plan is fully self-contained: it touches only utils.py and a new test file.
It shares no files with any other Phase 24 plan and runs in parallel (Wave 1).
</objective>
