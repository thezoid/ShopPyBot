<objective>
Wire the monitor-only run mode end to end: (1) an orchestrator gate in `_check_and_buy` that skips `_try_auto_buy` when `debug.monitor_only` is True (after stock alerts have fired), (2) a `--monitor-only` CLI flag on the `run` subparser that mutates `cfg.debug.monitor_only`, (3) a `monitor_only` ALLOWLIST entry so `config set monitor_only true` works, and (4) a CVV-prompt short-circuit when monitor_only is active.
