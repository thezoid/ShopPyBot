<objective>
Guarantee every newly-written log line carries a machine-parseable `[plugin]` tag (FC-01, completes the v4.1-deferred OBS-08). The tag is injected from a module-level `contextvars.ContextVar` in `logger.py`, set once per plugin task in `core/orchestrator.py:supervise()`. Lines with no active plugin (startup, web tier, service init) fall through to a `[core]` sentinel. The level bracket stays FIRST so every existing filter and the dashboard color regex keep working.

Purpose: This is the foundational format change the `/api/logs` plugin filter (Plan 34-02) builds on. Building the filter on today's inconsistent hand-written `[ClassName]` prefixes would be unreliable — this plan makes the tag a guarantee from the single write point.
Output: `logger.py` ContextVar + `set_log_plugin()` + new line format; `core/orchestrator.py` wiring; tag-injection + format-compat tests.
</objective>
