<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local clone to origin (tag push) | A ref write to the remote that becomes the phase's only rollback point |
| Local clone to origin (PR merge mutation) | A write that changes the default branch's history for every consumer |
| GitHub branch protection to merge command | The protection rules are the control; the merge command is the actor that can bypass them |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-36-01-01 | Tampering | `pre-v5-mainline` tag (overwrite destroys the rollback point) | high | mitigate | Pre-check `git ls-remote --tags origin refs/tags/pre-v5-mainline` and STOP if non-empty; `git tag -f`, `git push --force`, and tag deletion are prohibited by name in task 1; annotated-tag type asserted so a later lightweight overwrite is detectable |
| T-36-01-02 | Elevation of Privilege | `gh pr merge --admin` on PR #12 masking a genuine failing required check | high | mitigate | `--admin` prohibited by name in task 2; checks polled to a terminal bucket before merging; timeout action is STOP and escalate, never bypass |
