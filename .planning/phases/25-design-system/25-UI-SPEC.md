## FOUC Prevention Contract

The inline script is the FIRST child of `<head>`, placed before any `<link>` element. It runs synchronously before the browser requests any CSS. It must be inlined directly in the template — not a `src=` external file.

```html
<head>
  <script>
    (function() {
      var t = localStorage.getItem('theme');
      if (t === 'dark' || t === 'light') {
        document.documentElement.dataset.theme = t;
      } else if (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
        document.documentElement.dataset.theme = 'dark';
      }
    })();
  </script>
  ...CSS links...
</head>
```

If no stored preference and no `prefers-color-scheme` match, no `data-theme` attribute is set. The `:root` block (light) is the default. This means the attribute is absent in light-pref browsers, which is fine — light is the base `:root`.

## XSS Fix Contract

Scope: fix all `innerHTML` usages that interpolate API-sourced values. Replace with `textContent` / `createElement`. Add one helper function.

**Helper function (add to `<script>` block in `dashboard.html`):**

```javascript
function escHtml(str) {
  const d = document.createElement('div');
  d.textContent = str;
  return d.innerHTML;
}
```

`escHtml()` is for unavoidable SVG string interpolation only. All table and list construction must use `createElement` + `textContent` assignment — not string template literals in `innerHTML`.

**Specific fixes required:**

| Location | Current (broken) | Required fix |
|----------|-----------------|--------------|
| `loadItems()` line ~241 | `tr.innerHTML = \`<td>${item.name}</td>...\`` | `createElement` each `<td>`, set `textContent` for name, link, auto_buy, quantity; safe DOM for button with `addEventListener` |
| `loadCredentials()` line ~254 | `div.innerHTML = \`...\${cred.name}...\`` | `createElement` each child span/input/button; set `textContent` for `cred.name` and `cred.is_set`; wire `onclick` via `addEventListener` |
| `loadItems()` empty-state | `tbody.innerHTML = '<tr><td ...>No items...</td></tr>'` | Static string is safe (no API data); may stay as-is OR use `createElement` for consistency. Executor's choice. |

**CI assertion (add to test suite):**

A grep/test must verify no `innerHTML` assignment interpolates an API-sourced variable. Pattern to block: `innerHTML\s*=\s*.*\$\{(item\.|cred\.|data\.|cfg\.|resp\.)`. This assertion is a done-condition for Phase 25 close.
