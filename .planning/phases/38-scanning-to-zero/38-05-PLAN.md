<objective>
Empty the code scanning queue of everything that is not a real finding, one alert at a time with a
stated reason, and turn on the two secret scanning options that are currently off.

Purpose: a queue full of known-benign findings is a queue nobody reads, which is how a real finding
gets missed. The fix is per-alert dismissal with a specific reason, not a path filter. A
`paths-ignore` on `tests/` would clear the same 19 alerts today and would also hide every future
finding in those files, including a real one. That trade is not acceptable and this plan does not
make it.

Output: 26 dismissed alerts with recorded reasons, two repository settings enabled, and the
evidence for each re-queried from the API. That is 26 of the 31 open code scanning alerts. The
other 5 leave the queue by a source fix in earlier plans of this phase, not by dismissal: `#3`,
`#4`, and `#5` via `core/urls.host_matches` in SCAN-03, and `#33` and `#34` via workflow
permissions in SCAN-05. Both routes are legitimate and they are not the same thing, so this plan
states which alert took which route rather than reporting a single zero.

This plan changes no source files. Every action is a GitHub API mutation followed by a re-query.
</objective>
