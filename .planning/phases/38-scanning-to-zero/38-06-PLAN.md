The sequence below is a hard ordering. Every step must pass before the next runs. If any step
fails, stop with the branch intact. A deleted branch whose commit was never tagged is unrecoverable
once GitHub garbage-collects the unreferenced object.

**Run steps 1 through 5 as ONE shell invocation.** This is not a formatting preference. The
execution harness does not carry shell environment between separate command calls, so `DEVSHA` set
in step 1 would be EMPTY in a separately invoked step 2. With an empty `DEVSHA`,
`git rev-list --count "origin/master..$DEVSHA"` silently degrades to `origin/master..HEAD` and exits
`0`, which reads as a passing safety check while measuring nothing. The delete must live in the same
shell as the values that authorize it, under `set -euo pipefail`, so that no guard can be skipped by
a call boundary.

```
set -euo pipefail

# ---- Step 1: re-measure. Do not trust the planning-time SHA. ----
git fetch origin --prune --tags
DEVSHA=$(gh api repos/thezoid/ShopPyBot/branches/dev --jq .commit.sha)
echo "DEVSHA=$DEVSHA"
[ ${#DEVSHA} -eq 40 ] || { echo "FATAL: DEVSHA is not a 40-char sha, refusing to continue"; exit 1; }
[ "$DEVSHA" = "65ef2b906ed4b6aca85ccf4e02e42deff80174e3" ] || { echo "FATAL: dev head moved since planning, stop for a human"; exit 1; }
AHEAD=$(git rev-list --count "origin/master..$DEVSHA")
BEHIND=$(git rev-list --count "$DEVSHA..origin/master")
ANCESTOR_EXIT=0
git merge-base --is-ancestor "$DEVSHA" origin/master || ANCESTOR_EXIT=$?
echo "ahead=$AHEAD behind=$BEHIND ancestor_exit=$ANCESTOR_EXIT"
[ "$AHEAD" -eq 1 ] || { echo "FATAL: expected ahead=1, got $AHEAD"; exit 1; }
[ "$ANCESTOR_EXIT" -ne 0 ] || { echo "STOP: commit is already reachable from master, tag unnecessary, see note below"; exit 1; }

# ---- Step 2: create the tag on the remote ----
gh api -X POST repos/thezoid/ShopPyBot/git/refs -f ref=refs/tags/archive/dev-final -f sha="$DEVSHA"

# ---- Step 3: verify the tag before touching the branch ----
gh api repos/thezoid/ShopPyBot/git/ref/tags/archive/dev-final --jq '"a: type=\(.object.type) sha=\(.object.sha)"'
git tag -d archive/dev-final 2>/dev/null || true          # so c cannot pass on a leftover local ref
git fetch origin "refs/tags/archive/dev-final:refs/tags/archive/dev-final" --no-tags
LOCALTAG=$(git rev-parse archive/dev-final)
echo "c: local_rev_parse=$LOCALTAG"
[ "$LOCALTAG" = "$DEVSHA" ] || { echo "FATAL: fetched tag does not resolve to DEVSHA"; exit 1; }
OBJTYPE=$(git cat-file -t "$DEVSHA")
echo "d: object_type=$OBJTYPE"
[ "$OBJTYPE" = "commit" ] || { echo "FATAL: archived object is not a commit"; exit 1; }

# ---- The delete gate: fresh remote tag sha vs a freshly re-read live branch sha ----
TAGSHA=$(gh api repos/thezoid/ShopPyBot/git/ref/tags/archive/dev-final --jq .object.sha)
LIVESHA=$(gh api repos/thezoid/ShopPyBot/branches/dev --jq .commit.sha)
echo "e: tag_sha=$TAGSHA live_branch_sha=$LIVESHA"
[ ${#TAGSHA} -eq 40 ] || { echo "FATAL: tag sha is not a 40-char sha"; exit 1; }
[ "$TAGSHA" = "$LIVESHA" ] || { echo "FATAL: archive tag does not point at the live dev head, NOT deleting"; exit 1; }

# ---- Step 4: only now, delete the branch ----
gh api -X DELETE repos/thezoid/ShopPyBot/git/refs/heads/dev
echo "deleted refs/heads/dev at $LIVESHA, archived as refs/tags/archive/dev-final"

# ---- Step 5: re-query both sides. Assert on the HTTP STATUS VALUE, not on an exit code: a
# ---- network failure, an expired token and a 404 all exit nonzero, and only one of them means
# ---- the branch is gone. A bare nonzero exit here would read as a successful delete.
BRANCH_STATUS=$( (gh api --include repos/thezoid/ShopPyBot/branches/dev 2>/dev/null || true) | head -1 )
echo "branch_query_status=[$BRANCH_STATUS] (404 expected)"
case "$BRANCH_STATUS" in
  *" 404"*) ;;
  *" 200"*) echo "FATAL: branches/dev still resolves after the delete"; exit 1 ;;
  *)        echo "FATAL: branches/dev answered neither 200 nor 404 ([$BRANCH_STATUS]); the delete is UNVERIFIED, do not record SCAN-10 as done"; exit 1 ;;
esac
POSTSHA=$(gh api repos/thezoid/ShopPyBot/git/ref/tags/archive/dev-final --jq .object.sha)
echo "post_delete_tag_sha=$POSTSHA"
[ "$POSTSHA" = "$DEVSHA" ] || { echo "FATAL: tag no longer resolves to the archived sha"; exit 1; }
git fetch origin --prune
git ls-remote origin "refs/heads/dev" "refs/tags/archive/dev-final"
[ -z "$(git ls-remote origin "refs/heads/dev")" ] || { echo "FATAL: refs/heads/dev is still on the remote"; exit 1; }
```
