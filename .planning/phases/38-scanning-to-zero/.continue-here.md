## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| rtk log range blindness | `rtk git log HEAD..origin/branch` returned empty for a range containing 2 real merge commits. Empty reads as "branches are in sync", a confident wrong answer. Nearly produced a short MAIN-03 commit-audit record on a 263-commit merge. | blocking | Use `rtk proxy git log` for range or audit queries. Documented in `~/.claude/CLAUDE.md`, `~/.claude/RTK.md`, and `~/.claude/skills/rtk-hook/SKILL.md`. Cross-check any range result with `rtk git rev-list --count`. |
| Single-platform environment probe | The Phase 37 scout probed a clean wheel install on Windows only and declared the dependency gap fully mapped. `logger.py` imports `colorama` and `yaml` unconditionally; both reach Windows only via `click`'s win32 marker and `uvicorn[standard]`, and only under the `web` extra. A bare `pip install shoppybot` would have failed on every OS. | blocking | Read the source imports rather than trusting a probe's pass. Run environment gates on `ubuntu-latest` AND `windows-latest`. The Phase 37 wheel CI job now does this permanently. |
| Verifying config instead of artifact | Packaging correctness read back from `pyproject.toml` passes on a broken tree. It is how a dead wheel survived four milestones. | blocking | Build a real wheel and inspect its zip entries, then install into a clean venv and run the entry point. Never assert packaging from config text. |
| Plan names one call site when several exist | Wave 3's plan located the plugin path expression at `core/orchestrator.py:814`. It was also at `core/service.py:133` and `:159`. Implementing the plan literally would have made its own seam-guard test fail. | advisory | Grep for the pattern across the whole package before editing, not just at the line the plan names. |
| Gate never observed failing | A verification script that has only ever passed is not known to be a gate. | advisory | Deliberately break the thing and watch the gate fail, naming the right assertion. Phase 37 did this twice for the wheel gate. |
| Classifier denies executor dispatch | The harness auto-mode classifier denied `gsd-executor` dispatch for the PR #11 merge twice, including after the operator granted permission. | advisory | Run PR-merging steps inline in the main thread. Works, and is more visible. The orchestrator must then update STATE.md itself, since inline runs produce no per-plan state writes. |
