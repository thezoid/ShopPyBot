New helper on RetailerPlugin (core/plugin_base.py) — mirrors the existing getattr-safe idiom
(_session_enabled at plugin_base.py:272-282). Signature and three cases:
  def get_platform_config(self, model_cls: type[BaseModel]) -> BaseModel
    platforms = getattr(self.config, "platforms", None) if self.config else None
    key = getattr(self, "platform_key", None)
    raw = getattr(platforms, key, None) if key else None
    - raw is None                 -> return model_cls()          (defaults; missing config/key/section)
    - isinstance(raw, model_cls)  -> return raw                  (a built-in platform, already validated)
    - isinstance(raw, dict)       -> return model_cls(**raw)     (new plugin section; raises ValidationError on bad data — intentional)
    - else                        -> return model_cls()          (fallback)
  BaseModel must be imported into plugin_base.py (from pydantic import BaseModel).

Test/fixture pattern (RESEARCH.md "CFG-02 fixture-plugin test pattern"): write a shopbot_plugin_costco.py
