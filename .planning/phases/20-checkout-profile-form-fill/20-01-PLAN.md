<objective>
Create the checkout-profile data layer: the 9-key `CHECKOUT_PROFILE_KEYS` constant, the `CheckoutProfile` pydantic model, and the `load_checkout_profile()` loader that reads the keys from the CredentialStore and detects incomplete profiles. This is the foundation every downstream plan in Phase 20 builds on.

Purpose: Profile address data is PII stored off-disk in the existing CredentialStore (keyring / encrypted file), semantically distinct from secrets. Downstream plans (CLI setup, form-fill) consume this model and loader.
Output: `core/checkout_profile.py` (new), an isolation guard in/around `core/credentials.py`, and `tests/test_checkout_profile.py` covering all model-layer BUY-07 automated criteria.
</objective>
