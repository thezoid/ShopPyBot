|----------|-------------|
| terminal stdin → CLI | CVV typed by user at the run prompt; untrusted-but-local input |
| argv → main() | command-line arguments parsed by argparse |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Information Disclosure | CVV prompt in handle_run | mitigate | getpass.getpass (no echo); CVV passed to svc.run as parameter only, never printed or logged (SEC-02) |
| T-09-02 | Denial of Service | getpass in non-interactive stdin (CI/pipe) | mitigate | catch (EOFError, GetPassWarning), print stderr warning, return 1 — no crash/hang |
| T-09-03 | Tampering | top-level --migrate back-compat dispatch | accept | low risk; redirects to handle_setup which uses the same store seam; no new write path introduced here |
</threat_model>
