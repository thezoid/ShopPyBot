<objective>
Replace the Phase 22 no-op `restore_session()` stub on the `RetailerPlugin` ABC with a live implementation that decrypts the saved cookie list via `SessionStore` and restores it using the raw CDP path (`tab.send(cdp_storage.set_cookies([CookieParam(...)]))`), bypassing the confirmed nodriver `CookieJar.set_all()` bug. Add a generic `save_session()` that reads live cookies via CDP and persists them via `SessionStore`. Wire `save_session()` after successful login in Amazon/BestBuy (with `platform_key`), and wire startup restore into `registry.setup_for_items()` so the first run after a restart can skip login too (closing the research-flagged startup gap). All additive — `PLUGIN_API_VERSION` stays 2.

Purpose: This completes REL-04 and the cross-phase contract from Phase 22 — `relaunch()` already skips `login()` when `restore_session()` returns True, so enabling persistence transparently skips MFA on both relaunch and startup.
Output: live ABC hooks + startup wiring + 2 plugin edits + integration tests.
</objective>
