Otherwise mirror `EncryptedFileBackend._save` exactly: `salt = os.urandom(SALT_LEN)`; `key = _derive_key(self._passphrase, salt)`; `token = Fernet(key).encrypt(json.dumps(cookies).encode())`; create the parent dir with `self._dir.mkdir(parents=True, exist_ok=True)` BEFORE `tempfile.mkstemp(dir=str(self._dir))` (Pitfall 6 ordering); write `salt + token` inside an `os.fdopen(fd, "wb")` with-block; `os.replace(tmp, path)` AFTER the with-block (Windows-safe atomic write, Pitfall 6); on any exception unlink the tmp file (best-effort, swallow OSError) and re-raise.

Read bytes; split `salt, token = data[:SALT_LEN], data[SALT_LEN:]`; derive key; `try: plaintext = Fernet(key).decrypt(token)` and `return json.loads(plaintext)`. On `InvalidToken` OR any decode/JSON error, log `writeLog(f"SessionStore: {exc.__class__.__name__} restoring {platform}; falling back to login", "WARNING")` (class name ONLY — never the passphrase or cookie values) and return None. The contract differs from EncryptedFileBackend: restore returns None on failure, it does NOT raise ValueError (silent login fallback is the REL-04 contract).
