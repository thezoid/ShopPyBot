<objective>
Add the additive concrete `get_active_tab()` hook to the `RetailerPlugin` ABC. This is the
contract the orchestrator (Plan 04) calls to obtain the live confirmation tab after
`auto_buy()` returns True. The default returns `self.driver.main_tab`; checkout-capable
plugins (Amazon, BestBuy) override it in Plan 04 to return their last-navigated tab. The
hook is additive — `PLUGIN_API_VERSION` stays 2 (same non-breaking pattern as `get_price`).

Purpose: Decouple the orchestrator from plugin tab internals via a stable ABC hook, so the
6 non-checkout plugins inherit a safe default and only Amazon/BestBuy need an override.
Output: `get_active_tab()` default on the ABC + a test asserting the default and the
unchanged API version.

Note: This is the interface-contract plan in Wave 1. Plan 04 (Wave 2) supplies the Amazon
and BestBuy overrides and stores `self._last_tab`. This plan owns ONLY the ABC default and
must not touch any plugin file.
</objective>
