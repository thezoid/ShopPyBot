# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/)
as its code of conduct. All participants are expected to uphold these standards
in every project space, including GitHub issues, pull requests, and discussions.

## Our Standard

We are committed to providing a welcoming and harassment-free environment for
everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion, or
sexual identity and orientation.
